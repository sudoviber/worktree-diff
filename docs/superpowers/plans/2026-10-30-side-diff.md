## 执行中的判断记录
- T1：`hooks/layout.ts` 只有纯函数；diff 窗口按 quiet 画法的行计数（hunk 头也占一行，engine 样式沿用同一 offset，行数差由 T2 的 `height` + `overflow="hidden"` 吸收）；`windowHunks` 为窗口里每段生成 `@@ -a,b +c,d @@`（计数总是写出，空侧按 git 惯例写成前一行），只在窗口含真实 hunk 头时保留函数上下文，开头落单的 `\ No newline` 丢掉，hunk 头不可解析时返回 null 让调用方退回 quiet；用 `git apply --check --unidiff-zero` 验过这些合成 hunk，唯一例外是只含上下文行的切片（git apply 拒收无改动的 hunk，但 d.ts 的语法允许），需在 T2 用真引擎确认 Code 能画，不能就退回 quiet；指针落在分隔线 `│` 上算 diff 区。
- T2：tmux 实测 2.1.312（220 列终端 dock 约 98 列）：split/single、整棵树正好 bodyRows、焦点环随光标（文件名反色）、hunk 跳转、滚轮都按预期；只含上下文行的窗口交给 `Code format="diff"` 能画（带行号 gutter），合成 hunk 头不占行，engine 样式下 diff 区底部多出的空行由 `height` + `overflow="hidden"` 吸收，所以没有退回 quiet；滚轮：d.ts 写明 `ui.scroll` 在窗口两端也触发，实测内容放得下时仍有事件，按 `pointer.column` 分给两栏并且不调 `next`，没有 pointer 的方向键/翻页键交回引擎；新增 `treeOffset` 原子（spec 只列了 cursor/region/diffOffset，滚轮滚 tree 需要持久偏移），按键时用 `treeWindow` 写入、渲染只夹紧，滚轮滚 tree 时光标不动、可以滚出视野，下一次按键再拉回；提示行是每个热键一个 plain Button（热键只认画出的 Button，plain Button 必画成 `j: down`），所以文字是 `j: down  k: up  l: open  w: diff  h: fold  q: close  d: page  b: back  g: top  e: end` / `j: down  k: up  d: page  b: back  n: next  p: prev  h: tree  q: close  g: top  e: end  w: tree`，不是 spec 的 `j/k move …`，行高固定 1 行，放不下的 Button 被截掉但热键照常（实测单栏 66 列时被截的 e/g/w 都能按），n/p 只在 diff 区画、l 只在 tree 区画；点击或 Enter 落在非光标行时光标移过去、区域切回 tree，落在光标行（Enter 只会落在这里）时文件进 diff 区、目录折叠或展开（沿用 v0.3 的 Enter），`l` 在目录上沿用 v0.3 的 `l`；预览缓存就用 diffs 原子（按 `FileDiff.signature` 与 snapshot 比对，最多留 16 个），refresh 时强制重读光标所在文件并丢掉其它签名过期的；光标所在行消失时，refresh 先找原列表里它下方仍在的行、再找上方，被折叠藏起时去最近的可见祖先目录，t/z/折叠后同样写回 cursor；`columns: 120` 只在 side 模式请求，side 模式 `/wt-diff` 回 `FOCUSED_SIDE`；按键用的行数取最后一次绘制的几何（模块变量，热重载后首次绘制前按 10 行算，多个 surface 同时附着时取最后画的那个）；v0.3 的测试经包装的 `test` 默认带 `diffView: inline`，测试 painter 补了 `width`/`height`。
- T2 评审修复：diff 区按 Enter 与 spec 的「—」不同：split 下焦点环停在光标行，Enter 等同点击光标行，回到 tree 区；窄屏 diff 区光标行不画，焦点环改放在 `h` 的 Button 上（进入 diff 区时 `$.ui.focus` 过去，autoFocus 也指向它），Enter 同样回到 tree 区，T3 的按键表要据此写明；refresh、`t`、`z` 挪动光标时，光标挪动后焦点环跟到新行（窄屏 diff 区除外），并且这段修正放进 inTurn 和按键串行（toggleDir 只在按键的 turn 里调用，所以它里面不再包一层）；滚轮只在指针落在两栏的行上（含栏头行）时自己处理，落在顶部区域、提示行，或 rowBudget 放不下（fits=false、body 会溢出）时交回引擎；没画出两栏的绘制（读 git 中、notice）把 frame 清空，滚轮全部交回引擎。
- T3：README 中英文按实际实现写：按键表分 tree/diff 两栏，diff 区 `Enter` 写成「回到 tree」（窄屏焦点环在 `h` 上）；提示行照实写成 `j: down …` 并说明放不下的键被截掉但照常可按；点击光标行只在 tree 区时才「按下」它（diff 区点击只切回 tree）；v0.3 的行内按键表和整面板滚动的说明挪进「Inline view / 行内视图」小节；终端约 178 列才能左右并排（80 ÷ 45%）；Ambiguous 宽度列表里去掉了 `▾`（U+25BE 实为 Neutral，旧文有误），加上 `│`；面板矮到放不下时整体溢出滚动写进限制。
- 终审修复：刷新（含轮询）时光标没换行就不再把 tree 窗口拉回光标——光标原本在视野内则保持它在屏幕上的行（`refreshedTreeWindow`），被滚轮滚出视野则窗口不动；预览缓存的签名只含增删行数，内容变了行数没变时会显示旧 diff，所以光标停稳后总会重读一次（先画缓存，内容相同不写原子），不再按签名跳过；模式或 base（ref）变了时 diffOffset 归零，在 syncSide 里按前后 snapshot 比较，这样 `/wt-diff base`、`trunk` 也覆盖到；split 时分隔线两侧各留一格空白（tree 内容 paddingRight、diff 内容 paddingLeft，外层栏宽不变，regionAt/wheelRegion 不受影响）；删掉没被调用的 `windowOf`/`sourceWindow` 及其单测；version 改为 0.4.0。
