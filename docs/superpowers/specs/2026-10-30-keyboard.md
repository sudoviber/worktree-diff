# worktree-diff v0.3：键盘操作

日期：2026-10-30
状态：用户已确认（`/wt-diff` 直接把焦点给 pane；pane 内 vim 式 j/k）

## 问题
用户按键时字符进了 Claude Code 的输入框，因为 pane 没有键盘焦点。引擎规则如下：
- pane 只在 ctrl+x tab、鼠标点击或 `$.ui.open({ focus: true })` 之后拿到键盘；Esc 把键盘还给输入框。
- pane 拿到键盘后：Tab 在元素间移动，Button 的 `hotkey`（一个数字或小写字母）按下对应按钮，Enter 按下当前焦点所在的按钮，↑↓ 由引擎用来滚动。
- 插件不能注册全局快捷键。
- ↑↓ 只在内容超过一屏时才以 `ui.scroll` 事件出现，所以不能稳定地把它们改成逐行移动。

## 设计

### 进入与离开
- `/wt-diff`（无参数）改为「打开并聚焦」：
  - pane 没开、开着但被别的 tab 挡住、或已经显示时，都调用 `$.ui.open({ focus: true, ... })`。引擎只在输入框为空时才把焦点交出去，输入 slash command 之后输入框正好是空的。
  - 输出文本：`Changes pane focused — j/k move · enter open · esc back · q close`。
- 新增 `/wt-diff close`：关闭 pane。
- pane 内按 `q`：关闭 pane。引擎的 ctrl+x x 照常可用。
- Esc：引擎行为，回到输入框，pane 保持打开。

### pane 内按键（只在 pane 有焦点时生效）
| 键 | 作用 |
|---|---|
| `j` / `k` | 焦点移到下一行或上一行（文件行、目录行），并用 `$.ui.scroll({ to: { key } })` 滚到可见。焦点不在任何行上时（比如在控制按钮上），`j` 去第一行，`k` 去最后一行 |
| `Enter` | 引擎行为：按下焦点所在的行。文件行展开或收起 diff，目录行折叠或展开 |
| `h` | 焦点在已展开的目录上时，折叠它。在文件或已折叠的目录上时，焦点跳到父目录行。在顶层时不动 |
| `l` | 焦点在已折叠的目录上时，展开它。在文件上时，展开它的 diff。已经展开时，焦点进入第一个子项 |
| `g` / `e` | 跳到第一行 / 最后一行。热键按小写读取（`G` 等同 `g`，跳到第一行），所以「最后一行」不用 `G`，用 `e`（end） |
| `q` | 关闭 pane |
| 原有 | `a`/`c`/`u` 切模式，`r` 刷新，`t` 切树/列表，`z` 折叠全部目录，`x` 收起所有 diff |

- 焦点跟踪：观察 `ui.focus` 事件，只看本 pane 的 `requestId`，只记录不改写，把焦点所在元素的 key 存在模块变量里。热重载后这个变量会丢失，丢了就按「不在任何行上」处理。
- 行顺序：render 时把可见行的 Button key 按绘制顺序记到模块变量（不写 `$.state`）。tree 视图和 list 视图都适用，被折叠目录里的行不算。
- 进入 pane 时落点：给上次聚焦的那一行加 `autoFocus`；如果那一行已不存在，就给第一行加。没有任何行时不加。
- 移动焦点时用 `$.ui.focus({ requestId, key })`。返回 deny（例如 pane 没有键盘）时静默忽略。

### 提示行（pane 底部，dim）
- pane 没有焦点时显示一行 dim 文本：`ctrl+x tab to focus`。只在 terminal 上显示。
- pane 有焦点时显示按键行，用 plain Button 承载热键（热键必须挂在画出来的 Button 上）。内容是 `j: down  k: up  h: fold  l: open  g: top  e: end  q: close`，再接 dim 的 `esc: back`，空间不够时换行。
- 两行都放在内容最后。如果放在顶部，会把列表往下推；放在底部，列表滚动时提示会被滚走。实现时用 `e.props.scroll` 判断提示是否在视野外，判断不了就退而放在控制行下面。具体位置由实现者按引擎能力决定，记进判断记录。

## 验收
- 测试在 terminal 和 desktop 上覆盖：
  - `/wt-diff` 带 `focus: true`，`/wt-diff close` 能关闭，`q` 能关闭
  - j/k/g/e 在 tree 和 list 视图下按可见顺序移动，跳过折叠目录里的行，两端不越界
  - h/l 的目录和文件语义
  - 焦点丢失（热重载）后 j 去第一行
  - autoFocus 的落点
  - 提示行随 `isFocused` 切换
  - `$.ui.focus` 被拒绝时不报错
- validate、test、tsc 全部通过。README 增加一节「Keyboard」。
