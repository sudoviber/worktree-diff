# worktree-diff v0.4：右侧独立 diff 区

日期：2026-10-30
状态：用户已确认（右侧跟随光标预览；`w` 切换、`l`/`h` 进出；窄屏时 diff 占满整栏）

## 目标
在 tree 里移动光标时，右侧的独立区域实时显示当前文件的 diff。tree 和 diff 两个区域各自滚动，用快捷键在两者之间切换。

## 引擎约束（已核对 d.ts）
- 侧栏同一时刻只显示一个 pane，其余 pane 变成 tab，所以不能另开 pane 并排显示。左右两栏必须做在同一个 pane 里。
- `$.ui.open({ columns })` 可以请求更宽的侧栏，上限是终端宽度的 45%。用户拖动调整过的宽度优先。
- 引擎只滚动 pane 的整个 body，滚动位置在 `e.props.scroll`（offset、bodyRows）。要让两栏各自滚动，插件就要自己决定每一栏画哪一段：整棵树的高度正好等于 `bodyRows`，用 `Box` 的 `height` 加 `overflow="hidden"` 定住，引擎就没有可滚的内容。
- 只改变高度时引擎不会重绘，所以终端高度变化后，布局要等下一次状态变化才会更新。这一点作为限制写进 README。
- 热键只能是一个小写字母或数字。Tab 由引擎在元素之间移动焦点。

## 布局
- **split**：pane body 宽度 ≥ 80 列时使用。
  - 顶部保留 v0.3 的头部、操作行、模式标签和下划线、摘要行，都占满整宽。
  - 下面是左右两栏。左栏 tree，宽度为 `clamp(round(宽度 × 0.38), 28, 48)`；中间一列 dim 的 `│`；右栏 diff 占剩余宽度。
  - 最底部一行是按键提示。
- **single**（窄屏，< 80 列）：顶部区域同上，下面一次只显示一个区域（tree 或 diff），占满整宽。`w` 或 `h` 从 diff 回到 tree，`l` 或 `Enter` 从 tree 进入 diff。
- 打开 pane 时请求 `columns: 120`（引擎会截到 45%）。在 200 列的终端上大约是 90 列，就能用 split。
- 新增配置 `diffView`：`side`（默认，即上面两种布局）或 `inline`（保留 v0.3 的行内展开，键盘和行为与 v0.3 相同）。

## 区域与光标
- 光标：tree 中选中的行（文件行或目录行），存在 `$.state`（`cursor`，按行 key 存）。光标行的画法是行首加 accent 色的 `›`，名字加粗。焦点在 tree 区时，用 `$.ui.focus` 让引擎的焦点环跟随光标行；焦点环会把文件名反色，和光标一致。
- 区域：`region: 'tree' | 'diff'`，也存在 `$.state`。当前区域的栏头（` tree ` / ` diff `）用 accent 色，另一栏用 dim。
- 右栏内容：
  - 光标在文件上：显示该文件的 diff，自动预览。光标停稳约 120ms 后才加载，用 `loadFileDiff`，按「路径 + snapshot 签名」缓存。
  - 光标在目录上：显示该目录的汇总，即其下文件的列表和计数。
  - 列表为空：显示空状态。
- diff 区的第一行是文件路径和计数，后面是 diff 正文。正文用自己的逐行画法（quiet 样式，v0.3 的 drawLines）。
  - 只画可见窗口里的行。截断时超出窗口宽度的部分用 `…` 结尾，不做水平滚动。
  - 纯新增文件用 `Code format="source"`，`startLine` 等于窗口起始行号加 1，source 取窗口内的行。
  - `diffStyle: engine` 时，按窗口切片生成合法的合成 hunk 头，交给 `Code format="diff"` 画。实现太复杂的话可以退回 quiet 样式，但要写进判断记录。
- diff 窗口的滚动位置 `diffOffset` 存在 `$.state`，换文件时归零。

## 按键（pane 拿到键盘时生效）
| 键 | tree 区 | diff 区 |
|---|---|---|
| `j` / `k` | 光标下移 / 上移，tree 窗口跟着滚，右栏自动预览 | 向下 / 向上滚一行 |
| `d` / `u` | 光标下移 / 上移半屏 | 向下 / 向上滚半屏 |
| `n` / `p` | — | 下一个 / 上一个 hunk |
| `g` / `e` | 光标到第一行 / 最后一行 | 滚到顶部 / 底部 |
| `l` / `Enter` | 在文件上：进入 diff 区。在目录上：沿用 v0.3 的展开、进入行为 | — |
| `h` | 沿用 v0.3：折叠目录或跳到上级 | 回到 tree 区 |
| `w` | 切到 diff 区 | 切到 tree 区 |
| `q` | 关闭 pane | 关闭 pane |
| `a` `c` `u`、`r`、`t`、`z` | 原有功能 | 原有功能 |

- 在 side 模式下 `x`（收起所有 diff）没有意义，不画也不响应。inline 模式下保留。
- `u` 在 v0.3 里是切换到 uncommitted 模式。这里和半屏上翻冲突，所以 side 模式下半屏上翻改用 `b`（back），即 diff 区和 tree 区都用 `d` 和 `b`。`u` 仍然是 uncommitted 模式，不改。
- 所有热键各自只挂在一个 Button 上，Button 的处理函数按当前区域分派。

## 鼠标
- 点击 tree 的行：光标移到该行，区域切到 tree。
- 滚轮：如果引擎在内容放得下时仍然发出 `ui.scroll` 事件，就按 `pointer.column` 判断滚的是哪一栏：落在左栏宽度内就滚 tree 窗口，否则滚 diff 窗口，并且不调用 `next`，让引擎不滚整个 body。引擎不发事件的话就不支持滚轮，写进判断记录。

## 提示行
最底部一行，dim。内容随区域变化：
- tree 区：`j/k move  l open  w diff  h fold  q close`
- diff 区：`j/k scroll  d/b page  n/p hunk  h tree  q close`
- pane 没有键盘时，只在 terminal 上显示 `ctrl+x tab to focus`。

## 不变的部分
`/wt-diff status`、base 推断、模式、刷新、轮询、透明背景、状态栏都不变。`/wt-diff` 仍然是打开并接管键盘。
